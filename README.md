## 离线源码预览

> Source preview · Offline examples for a temporary macOS VPN session guard. Run the examples with Python 3.9+ and no administrator privileges.

临时会话保护用于降低 VPN 断线后流量回落到物理网卡的风险。现有原型用 macOS 的 PF 防火墙限制整机出站流量，并在工作应用退出后恢复原规则。此仓库提供经过脱敏的规则生成器、恢复判断示例和原型操作说明。运行示例只会输出预览结果。

## 现有面板的操作流程

以下操作适用于已经部署并完成本机验收的「Claude 会话」面板。该面板和管理员安装程序属于本机原型。

1. **开始**。连接本机配置的 VPN，打开会话面板，点击「开始保护」。在 macOS 系统窗口完成管理员授权，等面板显示「保护已核验」，再开始工作。
2. **工作中**。保持 VPN 连通。如果 VPN 断线或线路切换，暂停新的联网请求，先保存手头工作。会话设计为保留 PF 限制，直到用户主动结束。
3. **结束**。等任务结束并保存，用 `⌘Q` 退出工作应用和相关任务，再点击「结束工作并恢复网络」。等面板显示「未开始保护」，确认本轮已结束。
4. **断线后重开**。先走完退出和恢复流程，再重新连接 VPN，开启新会话并核验。面板无法完成恢复时，待相关任务退出后使用该机器上已验收的本地恢复入口，并以规则读回结果为准。

## 下载后怎样离线验证

需要 Python 3.9 或更新版本。进入仓库目录，运行：

```sh
python3 guard_preview.py rules examples/rules.json
python3 guard_preview.py recovery-check examples/recovery.json
python3 -m unittest discover -s tests -v
```

- `rules` 打印示例会话的 PF 锚点规则。示例只接受文档专用地址。规则先放行回环和指定隧道，为指定物理接口上的 VPN 对端 TCP 443 保留例外，最后丢弃其余流量。物理接口例外对整机进程生效。 [RFC 5737](https://www.rfc-editor.org/rfc/rfc5737.html)
- `recovery-check` 用合成快照检查任务退出状态、主规则和其他锚点是否仍与会话记录一致。示例返回 `check_ownership_before_recovery`。把 `tasks_exited` 改成 `false` 或给 `current.nat` 加一行会得到 `hold`。
- 单元测试检查规则顺序、输入校验、退出前拒绝恢复、外部规则变动以及恢复中断后的状态。示例仅用于阅读和核对，实际装载需要完整的本机验收和恢复程序。

## 原型怎样开始和恢复

原型只在预先验收的 PF 基线、应用版本和 VPN 通路满足条件时开始。管理员控制器先保存原规则和本会话的 PF 启用引用，再装载会话规则并读回核对。结束时先检查应用和相关任务是否退出，再核对主规则、会话锚点和系统规则。恢复只撤回本会话的变更并释放自己的启用引用，最后重新读回状态。遇到其他程序更改规则时，流程停下交由用户核对。
